# 인턴 예보관 브리핑북

지구과학Ⅱ(2015 개정) 실험·실습 3 「온대저기압 분석과 24시간 일기 예보」 사전 학습 페이지 (v2)

- 성취기준: [12지과Ⅱ05-03] ~ [12지과Ⅱ05-06], 지구과학Ⅰ ‘대기와 해양의 변화’ 연계
- 단일 `index.html` (외부 라이브러리·폰트·CDN 없음, 이미지 내장) → 학교망에서도 열림
- 구성
  - STEP 0: 일기도 기호, 위성영상 머리글, 바람깃, **자료 판독실**(자료 1~4 위경도 연동, 거리 재기)
  - 활동 1: 기압 경도 계산기, **힘의 평형 실험실**(지균풍 형성·지균풍·경도풍·지상풍, 실제 단위 계산)
  - 활동 2: 지도 위 편서풍 파동(풍속·수렴발산·지상 기압계), 축의 기울기 판정
  - 활동 3: 지도 위 온대 저기압의 일생(정체 전선~폐색기), 전선 단면, **가시·적외 실험실**(실제 영상 밝기 측정)
  - 활동 4: 시·공간 규모, 대기 대순환, 저기압 통과 시뮬레이터 + 시계열, 30초 브리핑(흐린 모범 답안)
- 과제 자료: 기상청 분석 일기도(2026.08.26. 00UTC), 천리안위성 2A호 VI006·IR105
- 지도 해안선: Natural Earth 1:50m / 1:10m (world-atlas)
- 연습 사례의 일기도·수치는 모두 가상 모식이며 과제 답이 아님

1. GitHub Desktop → File → Add local repository → 이 폴더 선택 (처음이면 “create a repository” 선택)
2. Commit → Publish repository (Public)
3. github.com 저장소 → Settings → Pages → Branch `main` / `/(root)` → Save
